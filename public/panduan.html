PUSAT BANTUAN

Panduan Penggunaan

Petunjuk praktis dari bot baru hingga online 24/7. Klik pertanyaan di bawah untuk membaca langkah lengkapnya.

Dokumentasi 10 Panduan
01 Bikin bot & sambungkan ke WhatsApp
  1. Buka Dashboard, klik tombol Tambah Bot, dan isi nama bot kamu.
  2. Bot akan muncul di grid berstatus Offline. Klik tombol Config untuk membuka kontrol bot.
  3. Klik Scan QR, lalu buka WhatsApp di HP: Titik Tiga → Perangkat Tertaut → Tautkan Perangkat, lalu scan kode QR.
  4. Tidak bisa scan? Gunakan Pairing Code dan masukkan 8 digit angka langsung di aplikasi WhatsApp HP.
  5. Tunggu status berubah jadi Online (biasanya 10–20 detik).
Catatan: Nomor yang ditautkan adalah nomor bot. Jangan gunakan nomor pribadi utama karena bot akan merespons pesan secara otomatis.
02 Memakai bot di grup
  1. Masukkan nomor bot ke dalam grup WhatsApp seperti menambahkan anggota biasa.
  2. Jadikan bot sebagai admin grup (opsional namun disarankan agar fitur moderasi seperti anti-link dan tutup grup bekerja).
  3. Ketik perintah .menu di grup untuk mengecek daftar fitur aktif.

Prefix bot bisa diatur bebas di halaman Config. Perintah tanpa prefix yang tepat akan diabaikan oleh sistem.

03 Mengatur nomor owner

Nomor owner adalah pemilik bot yang selalu dilayani tanpa batas, bebas dari kuota pesan harian.

  • Atur via Config → Pengaturan, atau ketik .addowner 628xxx dari nomor owner aktif.
  • Jumlah nomor owner dibatasi sesuai jatah paket langganan aktif kamu.
04 Kuota pesan & masa aktif

Sistem membedakan dua batas penggunaan:

  • Kuota harian: Direset otomatis setiap hari pada 00:00 WIB.
  • Masa aktif: Masa berlaku paket. Saat masa aktif habis, bot otomatis dipause dan aktif kembali setelah langganan diperpanjang.
05 Membayar & memperpanjang paket
  1. Buka menu Pricing, pilih paket sesuai kebutuhan kamu.
  2. Bayar dengan QRIS Otomatis atau QRIS Manual sesuai metode yang dipilih.
  3. Paket baru akan menambah durasi masa aktif yang ada secara kumulatif.
06 Bot tiba-tiba offline, kenapa?
  1. Masa aktif paket habis: Cek di profil akun dan lakukan perpanjangan.
  2. Aplikasi WhatsApp di HP dibuka bersamaan: Sesi tautan akan putus.
  3. Sesi kedaluwarsa: Buka Config, klik Clear Session, lalu scan ulang kode QR.

Cek halaman Log Aktivitas untuk mengetahui riwayat error secara terperinci.

07 Lupa password & ganti nomor HP

Kamu dapat mengganti password dan nomor telepon untuk notifikasi langsung di halaman Profil Akun.

08 Melihat semua command bot

Kunjungi katalog lengkap di halaman Command Manager untuk menyaring berdasarkan platform WhatsApp, Telegram, dan Discord.

09 Cara klaim Trial 5 hari gratis

Buka halaman Pricing, cari paket Trial dan tekan tombol Klaim Trial.

10 Mengubah prefix command

Masuk ke menu Config pada bot kamu, ubah karakter prefix (misal ! atau #), lalu klik Simpan.
